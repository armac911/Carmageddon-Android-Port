# Carmageddon Android Port 1.0

First tested AndroGaming.com release milestone, promoting the revised 0.2 code.

## Included

- Native ARM64 Android engine, dark launcher and ZIP import for your own PC data.
- Touch layout customization and remappable controller controls, including Select
  map, R3 camera and right-stick gear overrides alongside automatic shifting.
- 4:3/16:9, resolution/distance choices, palette-aware texture smoothing and
  60/120/144/uncapped presentation pacing.
- Profile-guided culling/readback/shadow optimizations, cross-GPU shadow fixes
  and optional local diagnostics, off by default.
- Complete setup/build documentation, AI disclosure, component credits and
  milestone changelog.

## Tested

Maintainer testing on Galaxy S24 FE (Android 16 / Xclipse 940) and Retroid Pocket
Flip 2 (Android 13 / Adreno 650): multiple completed races, plus installation,
import, saving/loading, controller defaults/remapping, car upgrades and stage 2.
The report covers the test pass collectively. 1.0 changes metadata/documentation
only; no new gameplay/rendering changes over the tested revised 0.2.

Requires Android 7+, ARM64, OpenGL ES 3.0 and your own compatible original
Carmageddon PC game data. No DATA/ or MUSIC/ content is included.
Network multiplayer is unavailable. Gear overrides retain automatic shifting.
The APK is development-signed/debuggable and retains the previous Next/Port key.
Install over the existing compatible app without uninstalling to preserve data.

See README.md for installation, limitations and the full AI disclosure.
